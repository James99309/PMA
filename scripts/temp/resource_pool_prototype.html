交互流程总结

请求方流程

  1. 1.在客户/项目列表页搜索关键词
  2. 2.受限记录: 半透明 + lock 锁图标 + 名称遮挡
  3. 3.点击受限行 → 弹出请求模态框
  4. 4.发送后: 锁变为 hourglass_top + 「请求中」标签
  5. 5.结果通知出现在「@我」Tab
  6. 6.通过后: 该记录变为正常行，可点击进入

审批方流程

  1. 1.请求出现在「待办」Tab
  2. 2.点击 → 弹出审批模态框
  3. 3.看到请求者信息 + 完整实体信息
  4. 4.勾选共享内容: 联系人/项目/跟进/报价
  5. 5.确认共享 或 拒绝
  6. 6.系统自动添加共享权限 + 通知请求者

特殊情况

  • - 归属人账户未激活 → 请求自动转发给其厂商的商务经理
  • - 已有待处理的请求 → 显示 hourglass_top 请求中，不可重复提交
  • - 报销单不参与共享（财务隐私保护规则）
