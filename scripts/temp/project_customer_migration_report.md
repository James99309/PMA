# 项目客户关联数据不一致问题报告

**生成时间**: 2025-10-13
**检查范围**: 本地数据库 pma_local (472个项目)

## 📊 问题概述

### 总体统计
- **总项目数**: 472
- **不一致项目数**: 54 (11.4%)
- **一致性比例**: 88.6%

### 问题分类
1. **旧字段有值但新关联没有**: 42个字段
   - 旧的项目表字段有公司名称，但ProjectCustomerAssociation表中缺少对应记录

2. **旧字段存储ID而非名称**: 2个字段
   - 存储了数字ID（例如"292"）而非公司名称
   - 可以通过ID反查到正确的公司

3. **旧字段包含空白字符**: 10个字段
   - 公司名称前后包含制表符、换行符等空白字符
   - 需要清理以确保正确匹配

4. **新关联有值但旧字段为空**: 5个字段
   - 这是正常情况，代表用户在新系统中添加的数据
   - 不需要修复

## 🔧 修复方案

### 自动修复范围
迁移脚本可以自动处理以下情况：

1. **精确匹配**: 旧字段公司名称在客户库中精确存在
2. **模糊匹配**: 公司名称部分匹配（如"厦门万安智能"匹配到"厦门万安智能深圳分公司"）
3. **ID转换**: 旧字段存储ID值，通过ID查找公司
4. **空白清理**: 自动清除前后空白字符

### 需要人工处理
1. **创建缺失公司**: 在客户管理中为无法匹配的34个公司创建记录
2. **验证模糊匹配**: 确认模糊匹配的公司是否正确
3. **项目详情手动添加**: 或在项目详情页通过"参与单位"功能手动添加

## 📈 预期修复效果

执行迁移脚本后：
- **将创建**: 约18个新的ProjectCustomerAssociation关联记录
- **将清理**: 10个包含空白字符的旧字段
- **将转换**: 2个ID值为正确的公司关联

**修复后一致性预计提升到**: 约92-95%
