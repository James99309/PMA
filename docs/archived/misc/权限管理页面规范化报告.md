## 🎨 视觉设计规范

### 徽章颜色体系
```css
/* 用户角色徽章 */
- 管理员: 红色系 (rgba(220, 53, 69, 0.4))
- 销售: 蓝色系 (rgba(0, 123, 255, 0.4))  
- 产品: 青色系 (rgba(23, 162, 184, 0.4))
- 服务: 绿色系 (rgba(40, 167, 69, 0.4))
- 厂商: 紫色系 (rgba(111, 66, 193, 0.4))
- 客户: 橙色系 (rgba(253, 126, 20, 0.4))

/* 用户状态徽章 */
- 已激活: 绿色系 (rgba(40, 167, 69, 0.4))
- 未激活: 黄色系 (rgba(255, 193, 7, 0.4))
```

### 透明度设计原则
- **背景透明度**: 40% (--badge-bg-opacity: 0.4)
- **文字透明度**: 80% (--badge-text-opacity: 0.8)  
- **边框透明度**: 60% (--badge-border-opacity: 0.6)

## 🔧 技术实现

### 文件修改
1. **`/app/templates/user/permissions.html`**
   - 导入标准化组件宏
   - 添加顶部通知容器
   - 替换所有按钮为标准化组件
   - 优化徽章和表格样式
   - 增强JavaScript交互功能

2. **`/app/templates/macros/ui_helpers.html`**
   - 新增 `render_user_role_badge` 组件
   - 支持6种用户角色类型
   - 遵循标准徽章设计规范

### 核心功能函数
```javascript
// 权限快速选择
window.selectAllPermissions()     // 全选可用权限
window.selectNonePermissions()    // 清空所有选择
window.selectViewPermissions()    // 设置仅查看权限

// AJAX保存
window.savePermissions(event)     // 无刷新保存权限

// 状态同步
updateAllCheckboxes()             // 同步"全部"复选框状态
```
