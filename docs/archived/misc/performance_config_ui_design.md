## 🧩 符合CLAUDE.md的组件使用

### 1. 页面结构遵循主要功能页面规范

### 2. 标准化按钮使用
- 使用 `render_button()` 组件
- 使用 `render_confirm_cancel()` 组件

### 3. 徽章组件使用规范
- 角色状态：已配置/待配置
- 项目计数：共 N 项
- 阈值等级：优秀/良好/合格

### 4. 卡片组件标准化
- 角色选择卡片
- 配置面板卡片  
- 绩效项目卡片

### 5. 表单组件规范
- 统一的输入框样式
- 标准化的下拉选择框
- 必填字段标记(*)

### 6. 响应式布局
- 移动端时左右栏变为上下布局
- 按钮组自适应排列
- 表格内容自适应滚动

## 🎨 颜色和样式规范

### 状态色彩
- 🟢 已配置：`bg-success` 
- 🟡 待配置：`bg-warning`
- 🔵 当前选中：`bg-primary`
- ⚪ 默认状态：`bg-secondary`

### 功能色彩
- 🟢 优秀：`border-left: 4px solid #28a745`
- 🔵 良好：`border-left: 4px solid #17a2b8`  
- 🟡 合格：`border-left: 4px solid #ffc107`
- 🔴 不合格：`border-left: 4px solid #dc3545`

### 交互状态
- 悬停：`transform: translateY(-1px)` + `box-shadow`
- 选中：`border-left: 4px solid #2196f3`
- 编辑中：`border-color: #28a745` + `background-color: #f8fff8`

## 📱 响应式设计

### 桌面端 (≥768px)
- 左右分栏布局
- 角色选择器固定宽度25%
- 配置面板自适应宽度75%

### 平板端 (576px-767px)  
- 左右栏各占50%
- 按钮组紧凑排列
- 模态框适配屏幕宽度

### 手机端 (<576px)
- 上下布局，角色选择器收起为下拉菜单
- 配置面板全宽显示
- 按钮组垂直堆叠

## 🔄 交互流程

### 角色切换流程
1. 点击左侧角色 → 2. 检查未保存更改 → 3. 显示确认对话框 → 4. 加载新角色配置

### 项目编辑流程  
1. 点击编辑按钮 → 2. 弹出模态框 → 3. 填写配置信息 → 4. 验证数据 → 5. 保存并更新列表

### 配置保存流程
1. 点击保存配置 → 2. 数据验证 → 3. 显示保存中状态 → 4. 成功提示 → 5. 更新状态徽章

这套设计完全遵循CLAUDE.md的组件规范，保持了系统的一致性，同时提供了专业的绩效配置管理界面。
