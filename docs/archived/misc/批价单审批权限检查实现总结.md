## 🎨 用户交互流程

### 正常审批流程
1. 用户点击"通过"按钮
2. 系统检查是否为批价单/结算单类型
3. 如无权限违规，直接执行审批

### 权限违规处理流程
1. 用户点击"通过"按钮
2. 系统检测到权限下限违规
3. 显示权限违规警告区域
4. 更新按钮为"确认通过"并变为警告色
5. 用户确认后继续审批，在审批记录中标记违规信息

## 📊 权限配置数据

### 现有权限下限配置 (从数据库分析)
```sql
-- 各角色权限下限示例
渠道经理: 批价单 45%, 结算单 40.5%
服务经理: 批价单 60%, 结算单 50%
销售总监: 批价单 40%, 结算单 38%
财务总监: 批价单 30%, 结算单 20%
管理员/CEO: 批价单 0%, 结算单 0% (无限制)
```

### 权限检查逻辑
```python
# 批价单折扣率检查
if current_pricing_rate < pricing_limit:
    violations.append("批价单折扣率低于权限下限")

# 结算单折扣率检查  
if settlement_limit > 0 and current_settlement_rate < settlement_limit:
    violations.append("结算单折扣率低于权限下限")
```
