## 一、角色定位

### 1.1 角色职责

解决方案经理是技术销售支持的核心角色，主要职责包括：

- 技术方案设计与支持
- 报价单产品确认
- 售前技术支持
- 新产品市场推广

### 1.2 系统关联

```
解决方案经理 (User)
│
├── Project.vendor_sales_manager_id  → 负责的项目
├── Quotation.confirmed_by           → 确认的报价单
├── WorkItem.owner_id                → 技术支持行程
└── 权限: 报价单全局编辑权、产品确认权
```

## 二、绩效指标体系

### 2.1 指标概览

| 指标类别 | 指标名称 | 权重建议 | 数据来源 |
|---------|---------|---------|---------|
| 确认效率 | 报价单确认率 | 25% | Quotation |
| 产品推广 | 新产品植入率 | 25% | QuotationDetail + Product |
| 客户服务 | 技术支持覆盖 | 25% | WorkItem |
| 业务成果 | 成功项目质量 | 25% | Project |

## 三、报价单确认率

### 3.1 指标定义

**报价单确认率** = 已确认报价单数 / 活跃项目报价单总数 × 100%

### 3.2 统计规则

| 规则项 | 说明 |
|-------|------|
| 统计范围 | 解决方案经理负责的项目 (`vendor_sales_manager_id`) |
| 排除条件 | 项目阶段为 `paused`(搁置)、`lost`(失败)、`signed`(已签约) |
| 确认判定 | `confirmation_badge_status = 'confirmed'` |
| 多次确认 | 只计算最终状态，多次确认算一次 |

### 3.3 项目阶段说明

| 阶段代码 | 中文名称 | 是否纳入统计 |
|---------|---------|-------------|
| discover | 发现 | ✅ 纳入 |
| embed | 植入 | ✅ 纳入 |
| pre_tender | 招标前 | ✅ 纳入 |
| tendering | 招标中 | ✅ 纳入 |
| awarded | 中标 | ✅ 纳入 |
| quoted | 批价 | ✅ 纳入 |
| paused | 搁置 | ❌ 排除 |
| lost | 失败 | ❌ 排除 |
| signed | 签约 | ❌ 排除（已成功） |

### 3.4 数据查询

```sql
-- 报价单确认率统计
SELECT
    u.real_name as 解决方案经理,
    COUNT(q.id) as 活跃报价单数,
    COUNT(CASE WHEN q.confirmation_badge_status = 'confirmed' THEN 1 END) as 已确认数,
    ROUND(
        COUNT(CASE WHEN q.confirmation_badge_status = 'confirmed' THEN 1 END) * 100.0
        / NULLIF(COUNT(q.id), 0), 2
    ) as 确认率
FROM users u
JOIN projects p ON p.vendor_sales_manager_id = u.id
JOIN quotations q ON q.project_id = p.id
WHERE u.role IN ('solution_manager', 'solution')
  AND p.current_stage NOT IN ('paused', 'lost', 'signed')
  AND p.is_deleted = false
GROUP BY u.id, u.real_name
ORDER BY 确认率 DESC;
```

### 3.5 评分标准

| 等级 | 确认率范围 | 说明 |
|-----|-----------|------|
| 优秀 | ≥ 90% | 报价单确认及时，技术支持到位 |
| 良好 | 70% - 89% | 确认工作基本完成 |
| 合格 | 50% - 69% | 需要加强跟进 |
| 待改进 | < 50% | 确认工作严重滞后 |

## 四、新产品植入率

### 4.1 指标定义

**新产品植入率** = 使用新厂商产品的项目数 / 活跃项目总数 × 100%

### 4.2 统计规则

| 规则项 | 说明 |
|-------|------|
| 厂商产品 | `Product.is_vendor_product = true` |
| 新产品定义 | 产品上市时间在统计周期内（建议90天） |
| 上市时间 | `Product.created_at` 或 `Product.productized_at` |
| 植入判定 | 产品出现在报价单明细 (`QuotationDetail`) 中 |

### 4.3 新产品判定逻辑

```python
# 新产品判定条件
is_new_product = (
    product.is_vendor_product == True
    AND (
        product.created_at >= (统计日期 - 90天)
        OR product.productized_at >= (统计日期 - 90天)
    )
)
```

### 4.4 数据查询

```sql
-- 新厂商产品植入率统计
SELECT
    u.real_name as 解决方案经理,

    -- 活跃项目数
    COUNT(DISTINCT p.id) as 活跃项目数,

    -- 使用新厂商产品的项目数
    COUNT(DISTINCT CASE
        WHEN prod.is_vendor_product = true
         AND prod.created_at >= DATE_SUB(CURDATE(), INTERVAL 90 DAY)
        THEN p.id
    END) as 新产品项目数,

    -- 植入率
    ROUND(
        COUNT(DISTINCT CASE
            WHEN prod.is_vendor_product = true
             AND prod.created_at >= DATE_SUB(CURDATE(), INTERVAL 90 DAY)
            THEN p.id
        END) * 100.0 / NULLIF(COUNT(DISTINCT p.id), 0), 2
    ) as 新产品植入率,

    -- 新产品植入金额
    SUM(CASE
        WHEN prod.is_vendor_product = true
         AND prod.created_at >= DATE_SUB(CURDATE(), INTERVAL 90 DAY)
        THEN qd.implant_subtotal ELSE 0
    END) as 新产品植入金额,

    -- 厂商产品植入总金额
    SUM(CASE
        WHEN prod.is_vendor_product = true
        THEN qd.implant_subtotal ELSE 0
    END) as 厂商产品植入总金额

FROM users u
JOIN projects p ON p.vendor_sales_manager_id = u.id
JOIN quotations q ON q.project_id = p.id
JOIN quotation_details qd ON qd.quotation_id = q.id
LEFT JOIN products prod ON qd.product_mn = prod.product_mn
WHERE u.role IN ('solution_manager', 'solution')
  AND p.current_stage NOT IN ('paused', 'lost', 'signed')
  AND p.is_deleted = false
GROUP BY u.id, u.real_name
ORDER BY 新产品植入率 DESC;
```

### 4.5 评分标准

| 等级 | 植入率范围 | 说明 |
|-----|-----------|------|
| 优秀 | ≥ 30% | 新产品推广积极，市场渗透好 |
| 良好 | 20% - 29% | 新产品有一定推广 |
| 合格 | 10% - 19% | 新产品推广一般 |
| 待改进 | < 10% | 需加强新产品推广意识 |

## 五、技术支持覆盖

### 5.1 指标定义

衡量解决方案经理在项目和客户上的技术支持工作投入。

### 5.2 相关工作类型

| work_type | 名称 | 说明 |
|-----------|------|------|
| `presales_support` | 售前支持 | 技术方案支持、产品演示 |
| `technical_support` | 技术支持 | 技术问题解答、方案优化 |
| `customer_visit` | 拜访客户 | 客户现场拜访 |
| `business_negotiation` | 商务洽谈 | 技术商务洽谈 |

### 5.3 统计指标

| 指标 | 计算方式 | 说明 |
|-----|---------|------|
| 技术支持次数 | COUNT(WorkItem) | 总工作项数量 |
| 技术支持时长 | SUM(actual_hours) | 总投入工时 |
| 客户覆盖数 | COUNT(DISTINCT customer_id) | 服务的不同客户数 |
| 项目覆盖数 | COUNT(DISTINCT project_id) | 支持的不同项目数 |
| 月均支持频次 | 总次数 / 统计月数 | 平均每月支持次数 |

### 5.4 数据查询

```sql
-- 技术支持覆盖统计
SELECT
    u.real_name as 解决方案经理,

    -- 技术支持次数
    COUNT(wi.id) as 支持次数,

    -- 技术支持时长
    ROUND(SUM(wi.actual_hours), 1) as 支持时长_小时,

    -- 客户覆盖
    COUNT(DISTINCT wi.customer_id) as 覆盖客户数,

    -- 项目覆盖
    COUNT(DISTINCT wi.project_id) as 覆盖项目数,

    -- 按类型统计
    COUNT(CASE WHEN wi.work_type = 'presales_support' THEN 1 END) as 售前支持次数,
    COUNT(CASE WHEN wi.work_type = 'technical_support' THEN 1 END) as 技术支持次数,
    COUNT(CASE WHEN wi.work_type = 'customer_visit' THEN 1 END) as 客户拜访次数

FROM users u
LEFT JOIN work_items wi ON wi.owner_id = u.id
WHERE u.role IN ('solution_manager', 'solution')
  AND wi.work_type IN ('presales_support', 'technical_support', 'customer_visit', 'business_negotiation')
  AND wi.status = 'completed'
  AND wi.is_deleted = false
  AND wi.planned_date BETWEEN DATE_SUB(CURDATE(), INTERVAL 30 DAY) AND CURDATE()
GROUP BY u.id, u.real_name
ORDER BY 支持次数 DESC;
```

### 5.5 评分标准（月度）

| 等级 | 支持次数 | 覆盖客户数 | 说明 |
|-----|---------|-----------|------|
| 优秀 | ≥ 20次 | ≥ 10个 | 技术支持活跃 |
| 良好 | 15-19次 | 7-9个 | 支持工作正常 |
| 合格 | 10-14次 | 4-6个 | 基本达标 |
| 待改进 | < 10次 | < 4个 | 需增加技术支持投入 |

## 六、成功项目质量

### 6.1 指标定义

衡量解决方案经理参与的成功项目（中标/签约）的数据质量。

### 6.2 成功阶段定义

| 阶段代码 | 中文名称 | 说明 |
|---------|---------|------|
| `awarded` | 中标 | 项目已中标 |
| `signed` | 签约 | 项目已签约 |

### 6.3 质量指标

| 指标 | 计算方式 | 说明 |
|-----|---------|------|
| 成功项目数 | COUNT(项目) | 中标/签约项目数量 |
| 成功项目植入总额 | SUM(implant_total_amount) | 厂商产品植入金额 |
| 平均确认周期 | AVG(confirmed_at - quotation.created_at) | 报价单确认响应速度 |
| 平均项目评分 | AVG(rating) | 项目质量评分(1-5星) |
| 技术支持深度 | AVG(项目WorkItem数) | 每个项目的技术支持投入 |

### 6.4 数据查询

```sql
-- 成功项目质量统计
SELECT
    u.real_name as 解决方案经理,

    -- 成功项目数
    COUNT(DISTINCT p.id) as 成功项目数,

    -- 植入总额（万元）
    ROUND(SUM(q.implant_total_amount) / 10000, 2) as 植入总额_万元,

    -- 平均确认周期（天）
    ROUND(AVG(DATEDIFF(q.confirmed_at, q.created_at)), 1) as 平均确认周期_天,

    -- 平均项目评分
    ROUND(AVG(p.rating), 2) as 平均项目评分,

    -- 技术支持深度
    ROUND(AVG(support_count.cnt), 1) as 平均技术支持次数

FROM users u
JOIN projects p ON p.vendor_sales_manager_id = u.id
LEFT JOIN quotations q ON q.project_id = p.id
LEFT JOIN (
    SELECT project_id, COUNT(*) as cnt
    FROM work_items
    WHERE work_type IN ('presales_support', 'technical_support')
      AND status = 'completed'
    GROUP BY project_id
) support_count ON support_count.project_id = p.id

WHERE u.role IN ('solution_manager', 'solution')
  AND p.current_stage IN ('awarded', 'signed')
  AND p.is_deleted = false
GROUP BY u.id, u.real_name
ORDER BY 成功项目数 DESC;
```

### 6.5 评分标准

| 指标 | 优秀 | 良好 | 合格 | 待改进 |
|-----|-----|-----|-----|--------|
| 成功项目数（季度） | ≥ 10个 | 6-9个 | 3-5个 | < 3个 |
| 平均确认周期 | ≤ 3天 | 4-7天 | 8-14天 | > 14天 |
| 平均项目评分 | ≥ 4.5 | 4.0-4.4 | 3.5-3.9 | < 3.5 |

## 七、综合绩效评估

### 7.1 综合评分计算

```
综合得分 = 报价单确认率得分 × 25%
         + 新产品植入率得分 × 25%
         + 技术支持覆盖得分 × 25%
         + 成功项目质量得分 × 25%
```

### 7.2 等级划分

| 综合得分 | 等级 | 说明 |
|---------|-----|------|
| 90-100分 | S级 | 卓越表现 |
| 80-89分 | A级 | 优秀 |
| 70-79分 | B级 | 良好 |
| 60-69分 | C级 | 合格 |
| < 60分 | D级 | 待改进 |

### 7.3 单项得分转换

| 单项等级 | 得分 |
|---------|-----|
| 优秀 | 100分 |
| 良好 | 80分 |
| 合格 | 60分 |
| 待改进 | 40分 |

## 八、数据表结构参考

### 8.1 核心数据表

| 表名 | 说明 | 关键字段 |
|-----|------|---------|
| `users` | 用户表 | id, role, real_name |
| `projects` | 项目表 | vendor_sales_manager_id, current_stage, rating |
| `quotations` | 报价单表 | confirmation_badge_status, confirmed_by, confirmed_at, implant_total_amount |
| `quotation_details` | 报价单明细 | product_mn, implant_subtotal |
| `products` | 产品表 | is_vendor_product, created_at, productized_at |
| `work_items` | 工作项表 | owner_id, work_type, project_id, customer_id, actual_hours |

### 8.2 数据关联图

```
User (solution_manager)
│
├─── Project.vendor_sales_manager_id
│    ├── current_stage (阶段筛选)
│    ├── rating (项目评分)
│    └── Quotation[]
│        ├── confirmation_badge_status
│        ├── confirmed_by, confirmed_at
│        ├── implant_total_amount
│        └── QuotationDetail[]
│            ├── product_mn → Product.is_vendor_product
│            └── implant_subtotal
│
└─── WorkItem.owner_id
     ├── work_type (支持类型)
     ├── project_id (关联项目)
     ├── customer_id (关联客户)
     └── actual_hours (工时)
```

## 九、系统实现建议

### 9.1 当前已支持

| 功能 | 状态 | 说明 |
|-----|------|------|
| 报价单确认状态 | ✅ | confirmation_badge_status 字段 |
| 厂商产品标记 | ✅ | is_vendor_product 字段 |
| 产品上市时间 | ✅ | created_at, productized_at 字段 |
| 技术支持记录 | ✅ | WorkItem 表完整记录 |
| 项目评分 | ✅ | rating 字段 |

### 9.2 建议增强

| 功能 | 优先级 | 说明 |
|-----|-------|------|
| 确认历史记录表 | 中 | 追踪多次确认/取消的完整历史 |
| 新产品标记字段 | 低 | 可配置"新品期限"参数替代 |
| 绩效统计API | 高 | 汇总计算各项指标的专用接口 |
| 绩效仪表盘 | 高 | 可视化展示绩效数据 |

### 9.3 配置参数建议

```python
# 绩效配置参数
PERFORMANCE_CONFIG = {
    # 新产品定义期限（天）
    'new_product_days': 90,

    # 排除的项目阶段
    'excluded_stages': ['paused', 'lost', 'signed'],

    # 技术支持工作类型
    'support_work_types': [
        'presales_support',
        'technical_support',
        'customer_visit',
        'business_negotiation'
    ],

    # 成功项目阶段
    'success_stages': ['awarded', 'signed'],

    # 权重配置
    'weights': {
        'confirmation_rate': 0.25,
        'new_product_rate': 0.25,
        'support_coverage': 0.25,
        'success_quality': 0.25
    }
}
```
