设计说明 — 采购订单详情页(v2)Design notes — Purchase Order detail (v2)
  • 进度条节点自带时间信息:每个阶段的完成时间 + 停留时长直接显示在节点下方,不再单列「阶段历史」卡。Each step shows its own timing — completion time + dwell duration sit right under the node; no separate "stage history" card.
  • 当前阶段节点可点击:点节点直接弹出该阶段操作(上传测试报告 / 推进 / 创建发货),不再有单独的「行动卡」。The current node is clickable — click it to open the stage action modal; no standalone action card.
  • 产出物即链接:已上传的确认单/测试报告,在对应节点下方以一行链接呈现。Deliverables as links — uploaded files show as a one-line link under the node.
  • 主体单列全宽:基本信息 / 订单明细 / 发货记录都占满整页宽度,去掉右侧栏。Full-width single column — info / items / shipments all span the full page; no sidebar.
