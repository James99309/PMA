设计说明 — 客户订单追踪页改造Design notes — Customer Order Tracking page
  • 销售订单详情页改造成「订单追踪页」:客户能看到从生产开始到签收的全过程进度。The Sales Order detail page becomes an order tracking page — the customer sees the full journey from production to delivery.
  • 发货只从采购单发起,SO 页移除「创建发货单」入口 → 本页全部只读。Shipments are created only from the Purchase Order. The "Create shipment" entry is removed here — this page is fully read-only.
  • 独立「发货记录」模块删除,发货详情改为本页弹模态查看。The standalone Shipment module is removed; shipment details open in a modal on this page.
