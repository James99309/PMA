  • • 沿用 PMA 现有 Tailwind 设计系统(primary #137fec + 卡片 rounded-xl border) • Uses PMA's existing Tailwind design system (primary #137fec + cards rounded-xl border)
  • • 极简优先:库存页只保留必要列;一个调整按钮 + 原因下拉强制结构化 • Minimalism first: only essential columns; single Adjust button with mandatory reason dropdown
  • • 权限感知单公司视图:库存页始终显示一家公司,顶部 switcher 切换(权限决定可切性) • Permission-aware single-company view: inventory page always shows one company; switcher in header (gated by permission)

  • • 客户公司详情页不加库存 Tab;库存只从库存管理模块访问 • Customer company detail page does NOT include inventory tab; inventory is only accessed from Inventory module
  • • 全局流水(All Warehouses)仅厂商管理员可见 • All Warehouses transactions log is visible to Vendor admin only
