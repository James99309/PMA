# PMA 系统更新说明 (2026-03-29)

## 一、报价单确认流程优化

### 销售人员

- **新建报价单后自动发起确认** — 不再需要手动点击"请求确认"，创建报价单后系统自动通知解决方案经理确认产品明细
- **报价单列表新增确认状态标识** — 报价单编号左侧新增彩色圆点，一眼区分状态：
  - 🟢 绿色 = 已确认
  - 🟠 橙色 = 待确认
  - 🟡 琥珀色 = 再次确认（配置变更后需重新确认）
- **新增确认状态筛选** — 报价单列表页筛选栏新增"确认状态"下拉，可快速筛选待确认/已确认的报价单
- **配置变更自动触发再次确认** — 编辑报价单时如果修改了产品行数或产品编码（MN号），已确认的报价单会自动变为"再次确认"状态，并重新通知解决方案经理

### 解决方案经理

- **待办中心收到确认任务** — 销售创建或修改报价单后，待办标签页会出现确认任务，点击可直接跳转到报价单详情页
- **确认操作自动记录日历** — 确认产品明细后，当天日历会自动添加一条"报价单确认"的售前支持工作记录，关联项目和客户
- **自动加入项目共享** — 确认报价单后，自动成为该项目的共享人员，后续可直接查看项目详情
- **老报价单已批量设为待确认** — 活跃项目下的历史报价单已统一设置为"待确认"状态，可在列表中通过筛选快速查看并逐步确认

## 二、操作行为自动记录日历

系统现在自动将以下操作记录到个人日历，无需手动填写：

| 操作 | 类型 | 说明 |
|------|------|------|
| 创建报价单 | 售前支持 | 记录从打开页面到保存的完整时间段 |
| 编辑报价单 | 售前支持 | 同天同报价单多次编辑合并为一条记录 |
| 报价单确认 | 售前支持 | 解决方案经理确认时自动记录 |
| 创建项目 | 售前支持 | 记录创建时间 |
| 项目阶段推进 | 售前支持 | 记录推进时间点 |
| 创建客户 | 客户拜访 | 记录创建时间 |
| 编辑客户 | 客户拜访 | 同天合并 |
| 创建/编辑联系人 | 客户拜访 | 同客户下同天合并 |
| 添加行动记录 | 客户维护 | 从客户或项目页面添加时记录 |
| 创建/编辑产品 | 产品研究 | 产品经理操作时记录 |

### 日历记录规则

- **同天合并** — 同一天对同一对象的操作合并为一条记录，不重复创建
- **时间累计** — 如果页面传入了打开时间，系统会计算操作时长并累计
- **操作日志** — 每次操作在描述中追加带时间戳的记录行，如：
  ```
  10:00 创建报价单
  10:30 编辑报价单
  14:00 编辑报价单
  ```
- **从日历手动创建的行动不受影响** — 仅自动记录上述系统操作，手动创建的日历事项保持不变
