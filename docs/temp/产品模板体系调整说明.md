# 产品模板体系调整说明

## 一、调整背景

在过去，产品库中的老产品与模板库中的规格指标命名不一致。例如，产品库使用「频率范围」，而模板库中使用规格字典的「工作频率」，导致系统在产品选择时将同一规格识别为两个不同的指标，影响报价时的规格聚合与比较。

为解决这一问题，我们对规格字典、产品模板和销售区域进行了统一调整。

---

## 二、数据源统一

**中国服务器作为唯一数据源**，新加坡服务器不再独立管理规格字典和模板库，所有数据统一由中国服务器维护并同步。

具体调整包括：

1. **规格字典合并** — 将语义相近的规格进行合并（如「频率范围」与「工作频率」合并为统一名称），所有产品经理可查看全局规格与指标，避免重复创建。
2. **指标命名规范** — 规格名称本身不再携带后缀（如单位），后缀由系统单独管理。
3. **销售区域统一** — 区域编码统一管理，用于区分中国地区与海外市场的产品配置。

## 三、产品模板与配置的关系

重新定义了产品模板和产品库之间的关系：

- **模板以型号为唯一标识**（如 MA10），一个型号对应一个模板
- **模板下包含多个配置版本**，每个配置代表一款独立 MN 编号的产品
- **每个配置绑定销售区域**，中国服务器和海外服务器会根据区域自动过滤，只显示对应区域的配置

## 四、创建模板和配置的建议

### 4.1 创建新模板 — 建议使用「复制」

在同一子分类（例如「室内天线」）下创建不同型号的模板（如 MA10、MA12）时，**建议复制已有模板**，而非从零新建。这样可以确保规格项的选择和排列顺序保持一致，减少出错。

### 4.2 新增配置 — 建议使用「复制」

在模板下新增配置时，同样**建议复制已有配置**，然后调整指标值或新增规格项。

**规格锁定机制**：
- 已被引用的编码规格，其位置会被锁定，只能调整指标值，不能移动
- 新增的规格项会自动排列在已有编码规格的下方

这确保了同一模板下或同一子分类下的所有配置，使用**一致的规格名称和编排顺序**。例如，「工作频率」始终在第一个位置。

## 五、模板配置进入产品库的方式

### 方式一：引入配置（适用于新产品）

1. 将配置的状态设置为「小批价」或「可生产」
2. 在产品库中，通过「引入模板配置」功能导入
3. 系统会根据当前服务器的销售区域自动过滤，只显示区域匹配的配置

`[图片5：产品库引入配置界面 — 展示配置选择列表和区域过滤]`

### 方式二：关联已有产品（适用于整理老产品）

当产品库中已有产品但规格指标不规范时：

1. 在模板下**复制一个正确的配置**
2. 调整该配置的规格指标，使其与已有产品一致（但使用规范的命名）
3. 在配置选项卡上点击**「关联」按钮**，选择产品库中已有的产品
4. 建立关联后：
   - 配置的 MN 编号会被产品的 MN 号**回填**
   - 配置中规范的规格名称和指标会**写入该产品**
   - **不会改变**已有产品的 MN 编号

通过这种方式，可以在不影响产品编号的前提下，整理和规范已有产品的规格指标。

## 六、总结

对于产品库中**所有已有的产品型号**，建议按以下流程操作：

```
建立型号模板 → 生成规范配置 → 导入新产品 或 关联已有产品
```

这样可以确保新配置与老产品的规格保持一致，使产品在报价选择时能够正确聚合和比较。
