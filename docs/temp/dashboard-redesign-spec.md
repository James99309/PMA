## 1. 背景与现状

### 1.1 业务现状
PMA 是和源通信（Evertac）内部 ERP，覆盖客户/项目/报价/批价/订单/采购/发货/库存/SN/报销/审批/任务/日报/会议/Wiki/AI 全链路。当前每日活跃用户 30+ 人，角色包括销售、SM（方案经理）、商务助理、采购、财务、CEO 等。

### 1.2 仪表盘与布局现状

当前 PMA 同时存在 **3 套侧边栏组件**并存：

| 组件 | 收起方式 | 顶部工具栏 | 谁在用 |
|---|---|---|---|
| `tw_sidebar.html` | w-0 完全消失 | 无 | 老 Tailwind 页面 |
| `tw_layout.html` | w-0 完全消失 | ✅ 有（9 个入口） | **仪表盘 (index.html)** |
| `at_sidebar.html` ⭐ | **64px 图标轨道 + hover 浮层 + pinned** | 无 | 采购订单、库存、销售订单、SN 等新页面 |

**问题**：
- 仪表盘还在用旧的 `tw_layout`，与新页面（采购/库存）视觉割裂
- 仪表盘内容是"被动信息流"（最近 5 个 X），缺乏"我该做什么"的语义
- 顶部工具栏功能很多但散乱，缺全局搜索和快速创建
- 侧边栏分组虽然合理，但配置项与业务项混在一起

### 1.3 仪表盘当前聚合的内容（需要保留/改造的）
1. 欢迎区（版本号、AI 分析报告入口、说明书下载）
2. 工作记录信息流（3/4 宽，无限滚动，按账户筛选）
3. 数据状态卡（KPI 进度条 + 多范围年度费用预算）
4. 最近项目 top 5（按 updated_at）
5. 最近报价 top 5（按 updated_at）
6. 最近报销（左侧 5 条 + 右侧年度总计 + 12 月折线图，按用户结算货币换算）
7. 团队 Skills 商店入口
8. What's New 弹窗

## 2. 设计目标

1. **统一视觉语言** — 全站迁移到 AT 风格（图标轨道侧边栏 + 卡片化主区域）
2. **从"信息流"到"任务流"** — 仪表盘第一屏是"等我处理的事"，而不是"系统里发生了什么"
3. **顶部工具栏整合** — 把 9 个分散入口重新组织，加上缺失的全局搜索 + 快速创建
4. **角色化** — 销售、SM、财务、CEO、商务助理看到不同的首屏
5. **保留数据宝藏** — 报销图表、KPI 预算、工作记录等已经做得好的不动

## 5. 顶部工具栏详细需求

### 5.1 布局

固定高度 56px，三段式：
```
[左] Logo + 系统名 + 国旗角标            [中] 全局搜索 ⌘K        [右] 操作集群
```

### 5.2 左侧（Logo 区）
- 应用 Logo（沿用 AT 现有的 8x8 蓝色圆形 ✓ 图标）
- "PMA" 文字（小屏隐藏）
- 国旗角标：🇨🇳 (CN NAS) / 🌏 (SG NAS)，根据 `currency_config.is_ovs` 切换
- 不需要侧边栏开关按钮（AT 侧边栏自己的 pinned 按钮在侧边栏内）

### 5.3 中间（全局搜索）⭐ 新增
- 占位符：`搜索客户、项目、报价、SN、产品... (⌘K)`
- 支持 `⌘K` / `Ctrl+K` 唤起聚焦
- 下拉结果分类：客户 / 项目 / 报价 / SN / 产品 / 用户
- 每类显示 top 3 + "查看全部 N 个结果"
- 实时模糊匹配（debounce 300ms）
- 输入框 max-w-md，居中显示

### 5.4 右侧（操作集群）
从左到右，每个图标按钮 40×40px：

| # | 入口 | 图标 | 行为 | 来源 |
|---|---|---|---|---|
| 1 | **快速创建** ⭐ 新增 | `+` add | 下拉菜单：新建客户/项目/报价/报销/任务/Action | 新功能 |
| 2 | 工作日历 | calendar_today | 跳转 `worklog.calendar`，未读用红圆点 | 沿用 |
| 3 | 我的任务 | task_alt | 下拉面板（保留现有 navTaskPanel） | 沿用 |
| 4 | 消息通知 | notifications | 下拉面板，含审批/@/系统消息 | 整合 |
| 5 | 快捷上传 | upload_file | 下拉拖拽框 | 沿用 |
| 6 | AI 聊天 | smart_toy | 侧边浮层 | 沿用 |
| 7 | 工作积分 | workspace_premium | hover 显示分数详情 | 沿用 |
| 8 | 帮助 | help_outline | What's New + 文档 | 沿用 |
| 9 | 语言 | language | zh/en 切换 | 沿用 |
| 10 | 用户菜单 | avatar | 头像下拉：个人/设置/登出 | 整合 |

**简化策略**：
- "工作积分"可以折叠进"用户菜单"
- "工作日历"可以并入"我的任务"成为"我的待办"统一入口
- 目标是把右侧从 9 个图标精简到 6-7 个

### 5.5 风险提醒条（条件性显示）
- 位置：top bar 下方一条窄条（h=32px）
- 触发条件：满足以下任一才显示
  - 待我审批 >3 天 ≥1
  - 报价超期未确认 ≥3
  - 库存低于安全水位 SN ≥1
  - 超期 Action ≥5
  - 报销审批卡 >5 天 ≥1
- 视觉：琥珀色背景 + ⚠ 图标 + 简短文案 + "查看详情"链接
- 一行内显示，多条用 · 分隔，超出折叠为 "+N 项"
- 可右侧 × 关闭（本会话不再显示）

## 8. 角色化首屏差异

| 角色 | 第一屏侧重 | 特殊卡片 |

### 9.4 响应式断点
- `< sm (640px)`：移动端不在本次范围（移动端 App 单独处理）
- `sm` 到 `lg`：单列堆叠
- `lg` 及以上：三列网格
- 卡片宽度自适应，不要硬编码

## 11. 交互细节

1. **加载状态**：所有卡片必须有 skeleton loader（避免空白闪烁）

3. **错误处理**：卡片级错误（不让单个 API 失败拖垮整页）
4. **刷新**：每个卡片右上角 ⟳ 按钮可单独刷新
5. **跳转**：所有 "查看全部 →" 必须带上对应筛选条件（如"待我审批" → 跳到审批中心已筛选）
6. **快捷键**：

   - `⌘N` / `Ctrl+N` 唤起快速创建菜单（可选）
7. **持久化**：用户自定义卡片顺序、隐藏的卡片 → localStorage
