## 四、考核标准与纳入口径

> 说明每项指标"**什么算、怎么算、按什么时间归属**"，使评分可复核。证据明细见 **附录 A**。

### 1. 销售额（已批价）
- **纳入**：本人**创建**的批价单，且状态为**已批价通过**（approved）。
- **计量**：金额取批价总额；多币种按各单据币种**折算为本位币**后求和。
- **时间归属**：按**批准时间**落入本季。
- **不纳入**：草稿 / 审批中 / 已驳回的批价单；他人创建的单据。

### 2. 植入价值
- **纳入**：本人为**负责人(owner)**的报价单中，**厂商产品**的植入额。
- **计量**：植入小计合计，多币种折算本位币。
- **时间归属**：按**报价单创建时间**落入本季。

### 3. 新增项目（合格）
- **纳入条件（须全部满足）**：① 未删除 ② 报备**通过**（有授权编号） ③ ≥1 条跟进记录 ④ 有**关联客户** ⑤ **≥1 张报价单**。
- **时间归属**：按**首次达标时间**落季——所有条件首次同时满足的那一刻盖戳，**永不重算**；后续补资料只计入**达标当季**，不回溯改动历史月份。
- **归属人**：项目负责人（owner）。

### 4. 新增客户（合格）
- **纳入条件（须全部满足）**：① 未删除 ② 公司**名称 / 地址 / 公司类型**齐全 ③ ≥1 名**联系人** ④ 客户下 **≥1 条跟进记录**。
- **时间归属**：同上，按**首次达标时间**落季，盖戳后永不重算。
- **归属人**：客户负责人（owner）。

### 5. 客户活跃率（水平指标 · 快照）
- **计量**：本人名下未删除客户中，状态为「高度活跃 / 活跃 / 正常」的占比；「待跟进 / 沉睡 / 流失」计为不活跃。
- **数据来源**：客户状态由系统每日 01:00 活跃度跑批维护。
- **特性**：快照型，反映**当前水平**，与季度窗口无关。

### 6. 项目活跃率（水平指标 · 快照）
- **计量**：本人**负责**（负责人或厂商销售）、且**未处于** 签约 / 暂停 / 失败 状态的项目中，**最近一次跟进距今 ≤20 天**的占比。

### 7. 个人丢单率（反向 · 水平指标）
- **计量**：本人负责项目中，本年被认定「**个人因素为主**」的失败项目数 ÷ 负责项目总数。
- **方向**：越低越好，实际 ≤ 目标即满分。
