info 交互流程说明
  1. 点击右下角聊天图标 → 手机端全屏打开，显示对话列表
  2. 点击某个对话 → 列表收起，聊天窗口最大化
  3. 点击左上角汉堡菜单 → 回到对话列表
  4. 点击右上角 ✕ → 关闭聊天面板
提示：使用浏览器 DevTools（F12）切换到手机模式（iPhone 12/13 等）查看最佳效果
