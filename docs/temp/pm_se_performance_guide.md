# 绩效考核指南 — 产品经理 & 解决方案经理

> 本手册帮助你理解：你的绩效数据从哪来、怎么算、如何提升。

---

## 你的绩效指标一览

### 产品经理 (PM)

| 指标 | 含义 |
|------|------|
| **产品植入额** | 你负责的产品被写进报价单时产生的金额 |
| **产品批价额** | 你负责的产品在批价单审批通过后的成交金额 |

### 解决方案经理 (SE)

| 指标 | 含义 |
|------|------|
| **支持项目植入额** | 你深度参与支持的项目中，报价单里厂商产品的植入金额 |
| **支持项目批价额** | 你深度参与支持的项目中，批价单审批通过后的总成交金额 |

---

## 产品经理篇

### 你的绩效从哪来？

作为产品经理，你的绩效**不取决于你自己做了多少报价**，而是取决于**你负责的产品在全公司范围内被使用了多少**。

举个例子：
> 你负责产品 A、B、C。销售小王给客户做了一份报价单，里面包含了你负责的产品 A（10个，市场价 ¥500/个），那么这 ¥5,000 的植入额就会**自动计入你的绩效**，即使这份报价单完全不是你创建的。

### 什么产品算"你负责的"？

系统通过两种方式判断产品归属：

1. **产品负责人** — 产品详情页上标注的"负责人"是你
2. **分类经理** — 如果产品没有直接指定负责人，但它所属的产品分类设置了你为经理

> 只要满足其中一种，该产品就算你负责的。

**注意**: 只有**厂商产品**才纳入统计。公司自有产品不计入产品经理绩效。

### 两个指标怎么算？

**产品植入额** = 你负责的所有厂商产品，在全公司所有报价单明细中出现时的金额汇总

```
计算方式：数量 × 市场价
时间节点：以报价单的创建日期为准
```

**产品批价额** = 你负责的所有厂商产品，在全公司已审批通过的批价单明细中的成交金额汇总

```
计算方式：成交单价 × 数量（即批价单明细行的总价）
时间节点：以批价单的审批通过日期为准
前提条件：批价单必须是"已审批"状态
```

### 如何提升你的绩效？

| 方向 | 具体做法 |
|------|---------|
| 推广产品 | 帮助销售团队了解你负责的产品，提高产品被写入报价单的频率 |
| 扩大产品线 | 主动认领更多有市场潜力的厂商产品 |
| 促成交易 | 协助销售推动报价单转化为批价单，并争取审批通过 |
| 维护产品归属 | 确保你负责的产品在系统中正确标注了你为负责人 |

## 解决方案经理篇

### 你的绩效从哪来？

作为解决方案经理，你的绩效**来自你深度参与支持的项目**。系统会跟踪你在每个项目中的实际贡献，只有贡献足够的项目才会计入你的绩效。

举个例子：
> 销售小李有一个项目需要技术支持，你被加入项目成员并担任"解决方案经理"角色。你在项目中创建了2条工作项，还记录了2次跟进行动，总共4次互动。这个项目就是你的"合格项目"。该项目后续产生的所有报价单和批价单金额，都会计入你的绩效。

### "合格项目"是什么意思？

并不是你挂名参与的每个项目都算你的绩效。系统设置了一个**参与门槛**：

> **你在项目中的互动次数必须 ≥ 3 次**

互动包括以下三类：

| 互动类型 | 什么算一次互动 |
|----------|--------------|
| 创建工作项 | 你在该项目中创建了一条工作项记录 |
| 被分享工作项 | 同事创建的工作项中，将你加入了分享列表 |
| 跟进行动 | 你在该项目中记录了一次跟进行动 |

**这三类互动的总数加起来达到 3 次**，该项目就成为你的"合格项目"。

**为什么要设门槛？**
这是为了确保绩效反映的是真正的深度参与，而非简单挂名。

### 两个指标怎么算？

**支持项目植入额** = 你的所有合格项目中，报价单里厂商产品的植入金额汇总

```
计算方式：厂商产品的 数量 × 市场价
时间节点：以报价单的创建日期为准
注意：只统计厂商产品的金额
```

**支持项目批价额** = 你的所有合格项目中，已审批通过的批价单总金额汇总

```
计算方式：每张批价单的总金额
时间节点：以批价单的审批通过日期为准
前提条件：批价单必须是"已审批"状态
注意：这里统计的是批价单整单金额，不限于厂商产品
```

### 如何提升你的绩效？

| 方向 | 具体做法 |
|------|---------|
| 深度参与 | 在项目中积极创建工作项、记录跟进行动，确保互动次数达标 |
| 主动支持 | 提前介入有技术需求的项目，增加合格项目数量 |
| 推动成交 | 用专业技术方案帮助销售赢下项目，推动报价转批价 |
| 记录留痕 | 每次技术支持后都在系统中记录行动，避免贡献被遗漏 |

## PM 与 SE 的核心区别

| | 产品经理 | 解决方案经理 |
|--|---------|------------|
| **视角** | 以**产品**为中心 | 以**项目**为中心 |
| **统计范围** | 全公司所有报价/批价单中，只看"我的产品" | 全公司所有报价/批价单中，只看"我参与的项目" |
| **归属判定** | 产品负责人 / 分类经理 | 项目成员表中的解决方案经理角色 |
| **门槛** | 无（只要产品归你就算） | 项目互动 ≥ 3 次 |
| **批价额范围** | 只算你负责的产品对应的明细金额 | 算项目整张批价单的总金额 |

> 简单理解：**PM 关心的是"我的产品卖了多少"，SE 关心的是"我支持的项目成交了多少"**。

## 在系统中查看你的绩效

1. 登录系统后，首页卡片会显示你当前的绩效进度
2. 进入个人详情页 → **绩效目标** 标签页，可查看：
   - 年度目标与达成率
   - 每月数据明细（实际值 / 目标值）
   - 趋势图表

如果看不到对应指标，说明管理员尚未为你的角色开启这些考核项，请联系管理员配置。

## 常见问题

**Q: 我负责的产品被写进报价单了，但我的植入额没有增加？**
- 检查该产品是否标记为"厂商产品"（自有产品不统计）
- 检查产品的"负责人"字段是否设置为你
- 报价单的创建日期是否在当前统计年度内

**Q: 我参与了一个项目，但绩效里没有体现？**
- 检查你在项目成员中的角色是否为"解决方案经理"
- 确认你在该项目中的互动次数是否达到 3 次（工作项 + 被分享 + 行动记录）
- 检查相关报价单/批价单是否已创建或审批

**Q: PM 的"产品批价额"和 SE 的"支持项目批价额"有什么区别？**
- PM 只算自己负责的产品在批价单中的**明细行金额**（只对自己的产品负责）
- SE 算整张批价单的**总金额**（对整个项目的技术支持负责）
- 所以同一张批价单，PM 可能只统计其中一部分产品的金额，而 SE 统计全部

**Q: 目标是谁设定的？**
- 由管理员在绩效配置页面为你设定年度目标
- 目标值按月分配，每月的达成率 = 当月实际 ÷ 当月目标
