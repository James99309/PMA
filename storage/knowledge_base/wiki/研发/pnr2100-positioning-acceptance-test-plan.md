# PNR2100 定位功能验收标准与测试方案

> 文档版本：V2.0 | 密级：内部使用 | 编制日期：2026-04-04
>
> 基于《PNR2100与云平台的功能开发PRD》及合同M3节点编制
>
> 合同M3节点：2025/11/28 → 2025/12/23

本文档由甲方编制，用于对乙方 M3 节点（核心定位引擎后端开发）交付成果进行系统性验收。

## 0. 文档说明与使用指引

### 0.1 编制目的

- **明确甲乙双方角色**：甲方提供 API 规范 / UI 规范 / PRD 作为开发参考；乙方按此实现定位引擎并接受验收
- **填补合同验收空白**：合同 M3 未明确精度指标和算法要求，本文档作为补充验收依据，需双方签字确认
- **可执行测试方案**：每个测试用例明确前提条件、操作步骤、通过/不通过标准，可直接在现场执行
- **与甲方规范对齐**：验收不只是接口能跑通，而是乙方实现必须符合甲方 API 规范、UI 规范和 PRD 要求

### 0.2 甲乙方角色与 M3 验收范围

| 维度 | 内容 | 说明 | 验收风险 |
|---|---|---|---|
| 甲方提供给乙方（开发参考） | ① 云平台终端定位 API 开放接口文档 ② 平台 UI 截图及交互规范 ③ PNR2100 功能开发 PRD | 作为规范和标准 | 甲方参考资料是否完整清晰直接影响乙方实现质量 |
| M3 节点乙方应交付 | 定位引擎后端独立开发完成（服务层代码 + 对外接口实现） | 乙方按甲方 API 规范和 PRD 实现定位引擎 | 合同未明确精度指标和算法要求，乙方可能以"接口跑通"为由主张 M3 完成 |
| 本文档验收范围 | 乙方实现是否符合甲方 API 规范、PRD 功能要求、精度标准 | 算法精度、参数可配置、日志可观测、业务闭环全部达标 | 需双方在验收前书面确认本文档作为 M3 验收正式依据 |

> ⚠️ **核心风险**：合同 M3 仅约定"定位引擎后端独立开发完成"，未明确精度指标、算法实现深度和参数可配置性要求。乙方可能以"接口能跑通、符合 API 格式"为由主张 M3 完成，但实际定位精度不达标、算法参数硬编码、无法现场调优。建议双方在验收开始前签署补充确认书，明确本文档作为 M3 验收正式依据。

## 第二部分：验收测试用例（TC-01 ~ TC-20）

共 20 个测试用例，覆盖室内静态/动态精度、信标稀疏降级、室内外切换、室外定位、跨楼层、无感知打卡、系统稳定性。

**优先级定义：**
- **P0 = 阻塞级**，任一不通过则整体 M3 不予通过
- **P1 = 核心**
- **P2 = 重要**
- **P3 = 扩展**

### 2.1 室内静态定位精度

#### TC-01 单点静态定位精度（P1 核心）

| 项目 | 内容 |
|---|---|
| **前提条件** | ① 测试点位于 3 个以上信标覆盖范围内；② 测试点真实物理坐标已知（卷尺量好并标记地面）；③ 乙方已完成基准点标定（Q-20 答案已提交） |
| **操作步骤** | 1. 将 PNR2100 放置在测试点，保持静止 2. 等待系统定位稳定（30 秒后开始计时） 3. 连续采集 60 秒内系统输出坐标（每秒 1 次，共 60 个点） 4. 计算每个点与真实坐标的欧氏距离偏差 5. 计算平均偏差、最大偏差、P90 偏差 6. 换到下一测试点重复，共 5 个点（走廊、房间内、拐角处、电梯口、靠窗各 1 个） |
| **通过标准** | ✅ 所有 5 个测试点均满足：平均偏差 ≤ 3 米 ✅ 所有 5 个测试点均满足：P90 偏差 ≤ 4 米 ✅ 最大单点偏差 ≤ 5 米 ✅ 60 秒内系统输出坐标数 ≥ 50 个 |
| **不通过标准** | ❌ 任意测试点平均偏差 > 5 米 ❌ 出现单次偏差 > 10 米的定位点 ❌ 60 秒内输出坐标数 < 50 个 |
| **记录要求** | 测试点编号/坐标/60 个原始定位值/平均+最大+P90 偏差；截图地图显示效果 |
| **特别说明** | 精度基线依赖乙方 Q-18~Q-20 答案。若乙方未提交标定数据，此用例结论记为【前提条件不满足，结果保留争议】 |

#### TC-02 静态抖动测试（P1 核心）

| 项目 | 内容 |
|---|---|
| **前提条件** | 设备放置在固定位置不移动，甲方前端地图界面正常显示定位点 |
| **操作步骤** | 1. 设备放置在已知位置，保持完全静止 2. 全程录屏记录地图上定位点移动情况，持续 3 分钟 3. 提取轨迹数据，计算连续定位点之间的跳动距离 |
| **通过标准** | ✅ 定位点抖动范围 ≤ 2 米直径（所有点在真实位置为圆心、半径 1 米的圆内） ✅ 无突发性大幅跳动（相邻两次定位点距离 > 5 米的次数 = 0） ✅ 3 分钟内无定位服务中断 |
| **不通过标准** | ❌ 设备静止但地图上的点持续大幅移动（卡尔曼滤波或 RSSI 预处理无效） ❌ 出现瞬移现象（距离 > 5 米） |
| **记录要求** | 完整 3 分钟录屏；导出 3 分钟原始坐标序列；标注最大抖动点 |

### 2.2 室内动态定位精度

#### TC-03 走廊直线行走测试（P1 核心）

| 项目 | 内容 |
|---|---|
| **前提条件** | 选择一段直线走廊（长度 ≥ 30 米），走廊两侧均有信标覆盖；走廊宽度已知 |
| **操作步骤** | 1. 人持设备从走廊一端匀速步行到另一端（正常步速约 1.2 m/s） 2. 全程录屏，同时导出轨迹坐标序列 3. 重复 3 次取综合结果 |
| **通过标准** | ✅ 轨迹整体沿走廊方向，偏出走廊边界的点 < 20% ✅ 全程无穿墙现象 ✅ 轨迹方向正确，无倒退现象 ✅ 轨迹连续，无空白段 > 5 秒 |
| **不通过标准** | ❌ 轨迹穿过墙壁进入相邻房间 ❌ 轨迹方向出现倒退 ❌ 轨迹锯齿严重（相邻点距离 > 走廊宽度 2 倍的点 > 20%） |
| **记录要求** | 录屏；导出原始轨迹坐标 CSV；地图截图标注实际行走路径 vs 轨迹对比 |

#### TC-04 拐弯测试（P2 重要）

| 项目 | 内容 |
|---|---|
| **前提条件** | 选择一个走廊拐角，拐角两侧各有信标覆盖 |
| **操作步骤** | 1. 从走廊直行，然后拐弯进入另一走廊或房间 2. 全程录屏记录轨迹 3. 重复 2 次 |
| **通过标准** | ✅ 轨迹在拐弯处体现出方向变化 ✅ 拐弯处无穿墙现象 ✅ 拐弯后轨迹在 ≤ 10 秒内跟上实际位置 |
| **不通过标准** | ❌ 轨迹直接穿墙切过拐角 ❌ 拐弯后轨迹长时间（> 15 秒）滞留在拐弯前位置 |
| **记录要求** | 录屏；地图截图标注实际路径与轨迹对比 |

#### TC-07 0 个信标区域（信号盲区）测试（P1 核心）

| 项目 | 内容 |
|---|---|
| **前提条件** | 从有信标覆盖区域走到完全无信标覆盖的区域 |
| **操作步骤** | 1. 人持设备从有信标区域匀速走到信号盲区 2. 在盲区停留 30 秒 3. 再走回有信标区域 4. 全程录屏 |
| **通过标准** | ✅ 进入盲区后：定位点保持最后已知位置，或前端显示信号丢失提示 ✅ 不会跳到默认坐标（如 0,0 或建筑外） ✅ 回到有信标区域后：定位正常恢复，≤ 15 秒内更新到正确位置 |
| **不通过标准** | ❌ 进入盲区后定位点跳到 0,0 或其他无关位置 ❌ 回到有信标区域后定位不能自动恢复 |

### 2.4 室内外切换测试

#### TC-08 室内→室外切换测试（P0 阻塞级）

| 项目 | 内容 |
|---|---|
| **前提条件** | ① 建筑物有蓝牙信标覆盖室内区域 ② 建筑出口处室外有良好 GPS 信号（卫星数 > 6） ③ 全程录屏 |
| **操作步骤** | 1. 从室内（蓝牙定位稳定）出发，匀速走向大门 2. 走出大门到达室外 3. 在室外停留 60 秒 4. 记录整个过程定位模式变化时间和定位坐标 |
| **通过标准** | ✅ 轨迹从室内平滑延伸到室外，无断点 ✅ 切换过程中无单次跳动 > 10 米的点 ✅ 切换延迟 ≤ 15 秒 ✅ 室外定位稳定后：平均偏差 ≤ 5 米 |

#### D.1 必须可配置参数清单及理由

判断标准：凡是会随客户现场物理环境或业务规则不同而必须变化的参数，必须可配置；纯算法内部调优参数可以硬编码。

| 编号 | 参数名称 | 所属模块 | 必须可配置的理由 | 关联验证项 |
|---|---|---|---|---|
| P-A | 信标 TxPower | RSSI 处理 | 每个客户现场信标硬件不同，取值必须跟随硬件变化 | Q-07/V-01/V-07 |
| P-B | 环境衰减因子 n | RSSI 处理 | 不同建筑材料/布局差异极大，每个客户现场必须独立标定 | Q-08/V-02/V-08 |
| P-C | 室内外切换 GPS 卫星数阈值 | 室内外切换 | 地下室入口与开阔楼宇入口 GPS 信号差异极大，固定阈值无法适配 | Q-10/V-03/V-09 |
| P-D | BLE 扫描频率 | RSSI 处理 | 不同对讲机硬件续航要求不同，频率需要现场权衡 | Q-23/V-04/V-10 |
| P-E | 打卡围栏半径/停留时间 | 打卡功能 | 每个客户打卡点位置和业务规则不同，是纯业务参数 | Q-23/V-05/V-11 |
| P-F | 切换防抖次数 N | 室内外切换 | 不同建筑入口结构差异大，固定 N 值在部分场景会失效 | Q-11/V-06/V-12 |

#### D.2 验收环境参数取值登记（乙方填写）

乙方须登记以下参数的验收环境默认值、取值来源（厂商标称值/现场实测值/经验估算值）、配置入口位置。取值来源影响甲方对精度基线的信任程度，**实测值优先级最高**。

登记参数项：
- P-A：TxPower（每个信标型号各填一行）
- P-B：环境衰减因子 n（同楼层）、n（跨楼层/隔墙，如适用）
- P-C：室内外切换 GPS 卫星数阈值、HDOP 阈值（如适用）
- P-D：BLE 扫描频率
- P-E：打卡围栏半径（室外 GPS 围栏）、打卡停留时间（室外 GPS 围栏）、打卡 RSSI 阈值（室内蓝牙围栏）、打卡停留时间（室内蓝牙围栏）
- P-F：切换防抖次数 N
