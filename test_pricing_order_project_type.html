功能使用说明
  1. 进入审批配置: 访问批价单审批流程模板配置页面
  2. 添加审批步骤: 创建新的审批步骤或编辑现有步骤
  3. 选择分支步骤: 将步骤类型设置为"分支决策步骤"
  4. 配置条件字段: 在条件字段下拉框中选择"关联项目类型"
  5. 设置比较值: 系统会自动加载项目类型选项：渠道跟进、销售重点、客户服务
  6. 完成配置: 保存步骤配置，实现基于项目类型的分支审批
可用的项目类型选项

  • 2销售重点 (sales_focus)
  • 3客户服务 (business_opportunity)
应用场景示例

场景: 不同项目类型需要不同的审批流程

  • 渠道跟进: 走渠道经理审批
  • 销售重点: 走销售总监审批
  • 客户服务: 走客服主管审批
