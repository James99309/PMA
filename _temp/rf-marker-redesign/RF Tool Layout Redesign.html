从「按钮一排」到「按职责分区」

不改功能，只重排信息架构。把现在塞在「RF 覆盖」下拉里的 12 个按钮 + 8 个勾选框， 按 工具 / 动作 / 图层 / 参数 / 全局 五类拆开归位 —— 这是让工具 "专业干净"的本质动作，视觉是其次。

① 三个组织原则 — 先选骨架
推荐 · 风险低

A · 专业 CAD 工作台

左工具栏 + 上下文顶栏 + 右检视 + 浮层图层
ctxsave

Figma / AutoCAD-web 同构。左侧竖工具栏选模式，顶栏只显示当前模式相关动作 + 全局保存导出， 右侧检视面板分组折叠，图层显隐独立浮层。学习成本最低，一眼专业。

B · 可停靠面板 / 高密度

右侧 Tab 面板：属性·图层·统计·RF参数
ctxsave

Ekahau / iBwave 同构。右侧多 Tab 可停靠面板，信息密度高，适合长时间规划作业的重度用户。 比 A 更强大但更重。

C · 模式驱动 / 极简画布

命令面板 ⌘K + 自动隐藏 chrome
save

Linear / Raycast 美学套到 CAD。画布优先，chrome 极简自动隐藏，命令面板唤起一切。 最"干净"但 UX 改动最大，老用户需适应。

左栏 = 从混乱下拉抽出的"绘制类"工具（模式互斥，点了就在画布画） 顶栏 = 当前模式的动作 + 全局保存/导出（不再 11 个平铺） 图层浮层 = 8 个勾选框归位，按 底图/RF/布线 分组 右检视 = 长列表拆成可折叠分组，上下文敏感 底部 HUD = 比例尺/计数/标定/缩放 统一一条，不再四角散落

这是结构蓝图，不是最终像素 —— 配色/字体/间距/图标都还会精修；天线标记沿用之前 「精炼测绘 V1」白 disc + 墨环（已嵌在画布里看连续性）。
