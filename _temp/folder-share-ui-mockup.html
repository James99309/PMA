颜色语义
  • 主操作 (primary #137fec)
  • 共享相关（已共享/共享给我）
  • 文件夹本色（不变）
  • 移除 / 收回 / 删除
角标语义
  • arrow_outward↗ 出射 = 我共享给别人
  • south_west↙ 入射 = 别人共享给我
  • 同色不同方向 = 一眼区分两种状态
交互一致性
  • • 共享方角标 / 头像组 / 卡片 → 任一可点击直达 Modal
  • • Modal 同时承担「添加」+「管理」两职责（含权限改 / 单个移除 / 全部收回）
  • • 被共享方无法重命名 / 移动 / 删除 → 仅能"离开此共享"
  • • 树状用户选择器复用 customer 共享同款
